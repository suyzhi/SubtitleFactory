# 字幕工厂设计归档

本目录存放历史设计方案，供参考和对比。

## v1-simplified-redesign (2024-09)

**设计理念**：简化操作流程，减少点击次数

**核心改进**：
- 自动转写：导入后自动完成下载→提取音频→转写
- 统一界面：视频播放器+字幕编辑合二为一
- 浮动进度：右下角显示处理进度，不干扰主界面
- 大卡片：项目列表使用16:9缩略图

**文件**：
- `v1-simplified-redesign.html` - 可直接在浏览器打开的演示
- `v1-simplified-redesign.css` - 样式文件

**状态**：已演示，用户反馈"还可以"，但希望更极致的版本

## v2-ultimate-redesign (2024-09)

**设计理念**：灵动的微动效 + 简约的视觉 + 丰富的功能，三者完美平衡

**核心改进**：
- 30+ 微动效：Logo旋转、按钮涟漪、卡片平移、进度闪烁等
- 玻璃态效果：搜索框和快捷按钮使用毛玻璃背景
- 弹簧动效：使用自定义贝塞尔曲线，元素到位后轻微回弹
- 延迟加载：列表项错落出现，有波浪感
- 精致视觉：多层阴影系统、统一圆角、精心调配的色彩

**文件**：
- `v2-ultimate-redesign.html` - 可直接在浏览器打开的演示
- `v2-ultimate-design-spec.md` - 详细设计说明文档（18页）

**状态**：已演示，用户反馈"还可以"，但暂不采用

**亮点**：
- 🎨 最精致的视觉设计
- ✨ 最丰富的动效系统
- 🎯 最完整的设计文档
- 🔧 最考虑性能的实现

**适用场景**：
- ✅ 追求视觉体验的用户
- ✅ 高性能设备
- ✅ 现代化风格偏好

**不适用场景**：
- ❌ 追求极致性能
- ❌ 低端设备
- ❌ 偏好无动效的简约
