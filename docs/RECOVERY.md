# 备份与故障恢复

字幕工厂默认保留 7 份每日备份和 4 份每周备份。可在“设置 → 备份与诊断”立即备份、恢复或打开备份目录。新备份同时写入 SHA-256 校验记录，恢复前会重新检查数据库结构、SQLite 完整性和校验值。

恢复不会在运行中覆盖正在使用的 SQLite。恢复入口先取得独占维护边界：已有写请求或后台任务会阻止恢复，一旦开始恢复，新的修改和任务也会被拒绝。App 随后创建当前数据库的安全备份，再将选中备份验证后排队；安全重启时才会在 sidecar 打开数据库之前原子应用。上次恢复来源和时间会保留在恢复回执中。

数据库迁移前会生成独立安全备份。任一迁移步骤失败时，应用将恢复迁移前数据库并停止启动，避免使用部分升级的数据。

异常退出后，正在运行的工作流会记录为中断；只有纯本地、未暂停的自动字幕工作流可在下次启动新建关联任务继续。暂停任务和云端音频请求不会静默重放，其他任务会在任务中心提供与类型一致的恢复入口。

字幕编辑历史和关闭自动保存时的草稿都跨重启保留。每次手动草稿修改先同步写入 WebView 本机恢复副本，再按顺序写入 SQLite；数据库确认最新版本后才清理恢复副本。“保存全部”会将正式编辑和清理草稿放在同一个事务。如果正式字幕在草稿之后已改变，App 只提供预览，必须显式确认才能将旧草稿应用到当前版本，且该操作可撤销。`Cmd/Ctrl + S` 会真实保存当前草稿。

模型下载中断后可在设置中重新准备或修复模型。磁盘不足时先释放空间再重试，不要删除项目数据库。需要反馈问题时导出脱敏诊断包。
