# 云端增强授权

- OCR、说话人增强、AI 质检、内容生成和 Fun-Realtime-ASR 云端转写是彼此独立的授权项。
- 首次开启时，界面会说明可能上传的内容类型；说话人增强仅应上传所选音频片段。
- 本地 OCR、离线说话人识别和规则质检不依赖授权，也不会读取授权作为自动回退条件。
- 可在“智能工具 → 云端增强授权”随时撤销。授权与撤销时间保存在本地数据库，便于审计。
- 更换 AI Provider 不会自动恢复已撤销的能力授权。
- Fun-Realtime-ASR 只有在百炼密钥已配置且用户单独确认后才会上传当前项目的分段音频；不会上传视频、文件路径或其他项目。撤销后模型立即回到“需要授权”状态。
