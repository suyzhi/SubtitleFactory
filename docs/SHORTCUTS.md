# 编辑器快捷键

| 操作 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | `Space` |
| 从头重播 | `R` |
| 前后一帧 / 小步移动 | `,` / `.` |
| 在播放头处拆分当前字幕 | `Cmd/Ctrl + Enter` |
| 编辑字幕时换行 / 保存 | `Shift + Enter` / `Enter` |
| 撤销 / 重做 | `Cmd/Ctrl + Z` / `Cmd/Ctrl + Shift + Z` |
| 保存当前草稿 | `Cmd/Ctrl + S` |
| 时间轴边界微调 | 聚焦边界后使用方向键 |
| 关闭弹层 | `Esc` |

播放相关按键（空格、`R`、`,`、`.`）在编辑与样式页任意位置生效；正在输入文字、焦点位于按钮或弹窗内时保持原有行为。

时间码、时间轴边界、流程卡片和主要操作按钮均可通过键盘聚焦。系统开启“减少动态效果”时，应用会降低非必要动画。
