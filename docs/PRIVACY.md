# 字幕工厂隐私说明

字幕工厂默认在本机处理媒体、音频、字幕、OCR、说话人识别、质检、术语表和翻译记忆。项目数据不会自动同步，也不会静默上传或在本地失败后自动回退云端。

Mac App Store 发行版不提供第三方网站媒体读取、Cookie 访问、持久监听文件夹或外部运行时路径，只接受用户主动导入并复制到受保护项目库的本地视频。直装版保留 YouTube 工作流：选择“网页播放”时，内嵌播放器会直接连接 YouTube，因此 YouTube 可按其政策接收常规播放器请求与网络信息；选择下载时，只应处理用户拥有明确权利的内容。

AI 翻译、整理和内容生成只在用户配置 Provider 并主动执行后调用，只发送当前操作所需的字幕文本和相关上下文。OCR、说话人增强、AI 质检、内容生成和云端转写分别保存授权记录；撤销后对应云端适配器必须停止调用。

Fun-Realtime-ASR 是可选的阿里云百炼转写能力。只有在用户保存百炼 API Key、阅读提示并单独授权后，App 才会把当时项目的 16 kHz WAV 音频分段上传；不会上传视频、文件路径、其他项目或本地数据库。授权会保留到用户主动撤销，每次转写仍必须由用户启动。第三方 Provider 对已接收数据的处理与保留同时受其服务条款和隐私政策约束。

API Key 存入 macOS Keychain，SQLite 仅保留引用与“已配置”状态。诊断包不包含密钥、媒体、字幕正文或完整用户目录路径。

本地 API 使用每次启动随机令牌和动态端口，媒体链接按项目签名并会过期。普通网页不能读取项目数据或调用修改接口。

字幕工厂不集成广告、跨 App 跟踪或行为分析 SDK。项目移入回收站时仍保留本地文件；只有用户确认永久删除、清空回收站或移除 App 数据时才会删除相应项目数据。云端 Provider 已接收的数据需要按对应 Provider 的删除机制处理。
