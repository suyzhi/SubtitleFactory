# 字幕工厂隐私说明

字幕工厂（简洁版）默认完全在本机处理视频媒体、16 kHz 音频提取与本地模型语音转写。项目数据与音频不会自动同步，也不会在本地处理失败后静默上传或自动回退云端。

Mac App Store 发行版启用 App Sandbox，不提供第三方网站媒体读取、Cookie 访问或外部运行时路径，只接受用户主动导入并复制到受保护数据目录的本地视频。直装版保留 YouTube 视频下载能力，仅应在用户拥有明确权利的内容上使用。

AI 字幕整理和 AI 翻译是可选的纯文本增强能力，只在用户填写第三方 Provider 的 API Key 并明确启用后调用，仅发送当前操作所需的字幕文本与相邻上下文，不会上传视频、音频、本机文件路径或其他项目数据。第三方 Provider 对已接收文本的处理与保留受其各自服务条款和隐私政策约束。

API Key 以明文保存在 App 数据目录下的本机 SQLite 数据库中，不使用 macOS 钥匙串；数据库升级前生成的本机备份文件同样包含这些密钥，复制或分享数据目录时请留意。

本地 API 使用每次启动随机令牌和动态端口，下载导出链接按项目签名并会过期。普通网页不能读取项目数据或调用修改接口。

字幕工厂不集成广告、跨 App 跟踪或行为分析 SDK。用户在应用内删除项目时，应用会永久删除对应的受管项目媒体、字幕、导出文件和数据库记录。云端 Provider 已接收的文本数据需按对应 Provider 的机制处理。
