## 已验证的证据

- 隔离数据目录完成普通文件导入、仅导入、首次生成、失败步骤重试、编辑保存、时间码定位保留输入焦点、候选比较/采用/撤销、SRT 与硬字幕 MP4 导出。CPU 模型和音频缓存均有实际命中记录。
- Computer Use 验证 1400×900 左右分栏、740×720 上下排列、比例记忆、专注模式、按需检查器；工具面板可进入质检、OCR、说话人和内容。
- 48 个隔离项目验证每页 40 条、第二页 8 条、紧凑列表；“已有字幕”筛选正确回到第一页、仅显示 2 个项目。启动不再额外取两份默认 100 条项目列表。
- 长任务运行时打开另一项目并导出，任务继续；暂停/取消在全局和项目面板使用同一任务快照。取消等待当前识别片段退出，有明确提示并保存转写草稿。
- 更改范围会提示所影响结果，保留现有字幕和历史；后端测试验证音轨、范围、文件/输出修改都会使准备缓存失效，相同选择不会重复失效。独立重新转写也校验媒体准备结果。
- 原“网页模式导出”说明已从当前前端移除。主入口保留两个新版 UI 标记，并使用 main.tsx → App.tsx。
- 后端回归 213 项与 25 个子测试通过；前端最新 73 项通过，类型检查和 lint 通过。发布脚本会再次验证包内运行时与入口。

模型和切段实验见 [实测报告](benchmarks/2026-09-06/REPORT.md)。固定样本、逐词输出、质量指标、RSS 和首结果时间均保留；没有真人逐词边界标注，没有以受并发负载影响的计时宣称固定加速比。激进参数只保留为实验脚本，默认值未改变。

文件、拖放和链接统一调用素材准备入口。普通文件入口完成实机全链路；远程下载与可选整理/翻译通过现有下载测试和模拟失败恢复测试覆盖，本轮没有向第三方服务发送测试音视频或用户文字。

最初复核发现的 486 条字幕项目，在真实数据接口和加载后的 UI 数量一致；原播放器隐藏 CSS 已修复。测试项目与真实用户资料分开。
